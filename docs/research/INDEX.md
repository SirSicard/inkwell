# Research index

All of these were written in March 2026, before v0.1 shipped. Most were then implemented. This index says what each one concluded and whether it still applies after the 2026-07 rehaul (free, open source, BYOK only, macOS first).

Status legend: **SHIPPED** = built, the doc is now a design record. **CURRENT** = still the plan. **SHELVED** = deliberately not doing it. **STALE** = superseded by newer facts.

| Doc | Conclusion | Status |
|---|---|---|
| [raw/01-ai-polish.md](raw/01-ai-polish.md) | BYOK LLM cleanup. `reqwest` plus a provider trait, since OpenAI/Groq/Cerebras/OpenRouter share the `/v1/chat/completions` shape and Anthropic is the outlier. API keys in the OS keyring via the `keyring` crate, never in settings. | **SHIPPED**, and the keyring rule is now a hard architecture constraint. The doc's usage-tracking section is dead: it existed to meter the free proxy tier, which is deleted. |
| [raw/02-chainable-transforms.md](raw/02-chainable-transforms.md) | Sequential multi-step LLM chains with per-step prompts, stored as JSON chain files, streamed over Tauri channels. | **SHELVED**. Power-user surface area for a product whose target user should not be building prompt pipelines. |
| [raw/03-per-app-styles.md](raw/03-per-app-styles.md) | Detect the focused app via the Win32 `GetForegroundWindow` chain, match on process name, apply a per-app style. About 1ms, call on demand, no polling. | **SHIPPED on Windows, STALE for macOS.** The Win32 approach does not port. macOS needs `NSWorkspace.frontmostApplication` and matching on bundle ID, not process name. Until then per-app styles silently no-op on Mac. |
| [raw/04-snippets.md](raw/04-snippets.md) | Snippet expansion belongs in the post-STT pipeline, not in a keystroke monitor, because we own the pipeline. `aho-corasick` for multi-pattern matching plus word-boundary filtering. | **SHIPPED.** Still the right design. Open product question is whether snippets deserve default visibility given that the OS already has text expanders. |
| [raw/05-voice-commands.md](raw/05-voice-commands.md) | Wake prefix plus command, matched on the transcribed text. No separate wake-word engine, no always-on listening. Whitelist-only execution with risk tiers. | **SHIPPED.** The whitelist and the no-always-on-listening stance are the parts worth preserving. |
| [raw/06-file-transcription.md](raw/06-file-transcription.md) | `symphonia` (pure Rust) covers about 95% of container formats without ffmpeg. VAD-chunk long files, two-pass for very large ones. Tauri's `tauri://drag-drop` event needs no plugin. | **SHIPPED.** Current implementation holds the engine mutex for the whole file, which blocks hotkey dictation. That is an architecture bug, not a research error. |
| [raw/07-export.md](raw/07-export.md) | TXT, SRT, JSON, CSV. SRT timestamps estimated by sentence-proportional distribution, because the models give no word-level timing. | **SHIPPED.** The timestamp caveat is still true and worth stating in the UI. |
| [raw/08-streaming.md](raw/08-streaming.md) | Two routes: true streaming with an `OnlineRecognizer` (Streaming Zipformer, 200ms chunks, partial and final events), or simulated streaming with VAD segments through the existing offline model. Recommends Zipformer first, then a hybrid where the offline model rescores. | **CURRENT, and the starting point for the streaming spike.** Caveat: the Zipformer choice predates better options. Moonshine v2's streaming encoder looks preferable on paper but sherpa-onnx runtime support is unverified, and on macOS an Apple SpeechAnalyzer or CoreML Parakeet sidecar could deliver partials without a second downloaded model. Treat the doc's pipeline shape (chunk loop, endpoint detection, partial/final events, hybrid rescoring) as sound and the model choice as open. |
| [raw/09-landing-page.md](raw/09-landing-page.md) | Astro 5 with React islands, R3F ink shader hero, GSAP scroll, platform-detected download. | **STALE but reusable.** The stack advice holds. The content does not: pricing and premium framing are gone, the site now needs a donation link and an honest unsigned-install section. |
| [model-catalog-research.md](model-catalog-research.md) | Survey of additional sherpa-onnx models to add: Moonshine Base, Parakeet V2, Canary Flash, Omnilingual 1600-language, FunASR nano. | **SHELVED, direction reversed.** The catalog is already 13 models, which is too many for a user who wants to dictate, not benchmark. The work is to cut to a curated three or four, not to expand. Keep the doc for its per-model file-layout details, which are useful when adding or removing engine constructors. |
| [voice-agent-integration.md](voice-agent-integration.md) | Second hotkey sends transcribed text to the OpenClaw gateway's OpenAI-compatible endpoint, agent responds in the overlay. | **DEAD.** OpenClaw was decommissioned 2026-06-15 and agent mode was removed in the rehaul. Kept only as a record. If voice-to-agent ever returns it must target a generic OpenAI-compatible or MCP endpoint, never a specific personal gateway. |

## What this set is missing

No research exists for the things that now matter most: macOS permissions and TCC behavior, code signing and notarization, Secure Input, Bluetooth microphone sample-rate handling, or distribution channels. Those are the current gaps.
