# S3.3a checklist: the WinUI shell on the desktop

What an agent's SSH session cannot check: the app needs an interactive desktop (launched over SSH,
WinUI fails fast in `Microsoft.UI.Input.dll` before any window exists). Run this signed in at the
PC, about 5 minutes.

## Build it

In a terminal, from the repository:

```
cd core
cargo build -p ink-ffi --lib
cd ..\windows
dotnet publish Inkwell\Inkwell.csproj -c Release -o %TEMP%\inkwell-app
```

Nothing is installed: the Windows App SDK's runtime is in the output folder. The core's library
is the debug build (release packaging comes with distribution).

## Launch

Optional, to keep your real library untouched: `set INK_DATA_DIR=%TEMP%\inkwell-check` first.
Then run `%TEMP%\inkwell-app\Inkwell.exe` from the same terminal.

- [ ] A window opens with Mica behind it (the desktop's colour shows faintly through), the Inkwell
      icon in the taskbar, and no separate title bar strip: "Inkwell" sits at the top left, with
      the minimise, maximise and close buttons.
- [ ] The big "Inkwell" is Sitka (a serif), the status line Segoe UI Variable, and the line under
      it (`core 0.0.0`) Cascadia Mono.
- [ ] The status reads "Ready" within a few seconds (the core started and sent `core.ready`). If
      it says "The core did not start: ...", note the text.
- [ ] Nothing on screen is blue. The only accent-coloured control in this empty shell is the ring
      that spins while the core starts (often under a second): if you catch it, it is sepia
      brown. The screens (next step) put the accent on real controls.
- [ ] The tray (notification area, maybe behind the ^ arrow) shows the Inkwell drop. Hovering it
      says "Inkwell".
- [ ] Right-click the tray icon: "Show Inkwell" and "Quit Inkwell".
- [ ] Close the window with its X: it disappears, the tray icon stays. Left-click the tray icon:
      the window comes back.
- [ ] Text is sharp at your display scaling (not blurry).

## Idle: 0 % CPU

With the window open and Ready, leave it untouched for 2 minutes, then open Task Manager,
Details tab, and find Inkwell.exe.

- [ ] CPU shows 00 (0 %) the whole time you watch (about 30 s). Write down the memory column.
- [ ] Same with the window hidden in the tray.

## Quit

- [ ] Tray > Quit Inkwell: the tray icon and the process (Task Manager) are gone within a few
      seconds, and no error dialog appears.

Report: which boxes failed, the memory figure, and any message the window showed.
