# S3.3b checklist: the screens on the desktop

What an agent's SSH session cannot check: the screens need an interactive desktop, a person's eyes
against the design canvas, ears for playback, and Narrator. About forty minutes, signed in at the
PC. The logic behind each line is unit-tested (`dotnet test windows\Inkwell.slnx`); this list is
how it looks, reads and sounds. Note the date, the Windows build and the commit at the end.

The ink areas are placeholders in this step (plain paper): the ink and the Drop are S3.4's.

## Setup

In a terminal, from the repository:

```
cd core
cargo build -p ink-ffi --lib
set SEED_UTC_OFFSET_MINUTES=120
cargo run -p ink-ffi --example seed_library -- %TEMP%\inkwell-screens
cd ..\windows
dotnet publish Inkwell\Inkwell.csproj -c Release -o %TEMP%\inkwell-app
set INK_DATA_DIR=%TEMP%\inkwell-screens
%TEMP%\inkwell-app\Inkwell.exe
```

(Set the offset to your time zone's, in minutes, so "by Friday" lands on Friday.) Every word in the
seeded library is synthetic; its audio is the AMI fixture replayed through the meeting chain.

- [ ] Size the window to about 1280 × 800 (the canvas's size) for the comparisons.

## 1. Narrator: every navigation item (Ctrl+Win+Enter turns Narrator on and off)

- [ ] Narrator names the window "Inkwell". Tab (or F6) reaches the navigation: Narrator announces
      it ("Sections") and each item by name with its position: Today, Library, Owed, then Settings.
- [ ] On each item in turn, press Enter or Space: the content changes to it, and moving into the
      content (Caps Lock+Right, or Tab) reads that screen's first heading. Every item.
- [ ] The arrow keys move through the items with the navigation focused.
- [ ] The ink rail beside the content is never announced (decorative); on Today, "Record now" at
      its foot is announced as a button.
- [ ] Narrator's heading list (Caps Lock+F6, or H to move by heading) lists each screen's headings.
- [ ] During a meeting (section 4), Live appears under "While recording" and is reachable the same
      way; when the meeting ends it leaves, and a window showing it goes to Today.
- [ ] The tray icon: Narrator reads "Inkwell"; its menu reads "Show Inkwell" and "Quit Inkwell".

## 2. First run

Start once on an empty folder (`set INK_DATA_DIR=%TEMP%\inkwell-fresh`).

- [ ] The first-run sheet shows over the window: four steps.
- [ ] Permissions step: "Hear you", "Hear the others", "Type for you", "Know your meetings", each
      with its state. Only the microphone can be asked for (the others need no permission on
      Windows and say so); "Know your meetings" says the calendar isn't available in this build.
- [ ] Polish step: the switch is off, and without a working language model it cannot be turned on,
      and the line under it says why. Nothing turns polish on without its consent step.
- [ ] Start (or Skip) closes it. Quit from the tray and start again on the same folder: it does not
      come back. On a new empty folder, Quit from the tray with the sheet up: the next start shows it
      again (quitting is not skipping).

## 3. Today, Library, a record (against the "Today" and "Library · a meeting record" boards)

- [ ] Today: the date in small spaced capitals, a greeting for the hour.
- [ ] Last meeting: its title is the summary's headline (not "Untitled" or a date); its line
      "Today 13:34 · 1 min · Zoom · Alex, Robin, Sam" (your times); the summary's first paragraph
      rendered (bold and italic as type, no `**` or `*`); it is the meeting that started last.
- [ ] "Open record" opens it in the Library. "Play from 00:02" opens it and plays from there
      (needs ears).
- [ ] Up next says the calendar isn't available in this build (Windows' calendar needs a packaged
      app; S3.6). Nothing asks for it.
- [ ] Owed soon: the first three of Owed, soonest first, each with a circle, its text, and its due
      day, record and "▸ 00:02"; an overdue one in seal red. "All N" opens Owed. The circle marks
      one done.
- [ ] The foot: "Dictated today · N words · …" and "This week · N meetings · …".
- [ ] The foot of the ink zone: "Listening for meetings" (or not) and "Hold Right Ctrl to
      dictate" (your key), and Record now.
- [ ] Needs you: turn the microphone off for desktop apps (Settings > Privacy & security >
      Microphone) and come back to Inkwell: "Inkwell can't hear you" with a button that opens that
      page. Turn it back on and come back: the card goes.
- [ ] Library: the chips Meetings, Dictations, Files; newest first; titles are headlines or first
      words, never "Untitled". Search "budget" finds the launch meeting's lines; "zebra" says
      nothing matches. An empty library shows a sentence, no command line or path.
- [ ] A record: title in Sitka, its line, Copy summary (paste in Notepad: no `#`, `**` or `- `),
      tabs "Notes and transcript", "Summary", "Owed · N".
- [ ] Notes and transcript: your notes with their time chips, what was said as you wrote; the
      ledger with times, a dot (ink for you, sepia for them), who, and the words.
- [ ] Summary: headings, bullets and numbers as a document; links as plain words; "Where it was
      said" under it.
- [ ] The player (needs ears): play/pause, both sides in step, the two-lane waveform, clicking a
      line or a chip plays from it and the playhead lands within a second of it, You and Them
      volumes. With no output device, it says the recording can't be played now.
- [ ] Idle with a record open and paused: Task Manager shows Inkwell at 0 % CPU.

## 4. Live and Owed (against the "Live meeting" and "Owed" boards)

Start a meeting with Record now (or wait for a call to be offered) and speak for a minute.

- [ ] Live: "Live meeting", the red dot with the running clock (the only thing that ticks);
      your lines and theirs in order, a grey settling line replaced as words settle.
- [ ] Notes: type a line, Enter, another, click elsewhere; edit one, delete one. After the meeting
      the record's notes match.
- [ ] Ask says it isn't available in this version, never a made-up answer.
- [ ] Owed: promises grouped, duplicates merged ("Said twice · merged"), overdue in seal red, due
      chips; marking one done removes it and it stays gone after a restart.

## 5. Settings (against the "Settings" board)

- [ ] Permissions: the four cards, their state now, true for Windows.
- [ ] Voice: the dictation key (Right Ctrl by default: hold, speak, let go), the voice-edit key
      (off by default; choosing a key shows its consent step first; Cancel changes nothing).
- [ ] AI: "Polish my words", "Voice edit" and "Summaries and Ask" each off on a fresh library, each
      turned on only through its own step naming where the words go; Cancel leaves it off; turning
      one on leaves the others off. With no language model, each says why and cannot be turned on.
- [ ] Modes: apps by name (never a raw `something.exe` when a name is known), with icons.
- [ ] Snippets and Voice commands: add, edit, switch off, delete; each change stays after a restart.
- [ ] Models: each job with its engine and measured accuracy.
- [ ] Meetings: listen for calls, the headset mic, how long to keep records; Storage: sizes true
      for this PC, "Show in File Explorer" opens the library's folder.
- [ ] About: the version, the model credits, and every component's notice (the Windows App SDK,
      WebView2, WinUIEx, .NET, wasapi-rs and the Rust crates), each opening to its full text.

## 6. Design

- [ ] Each screen beside its board: same order of parts, same words, same use of seal red. Note
      differences: ______
- [ ] Light and dark (Settings > Personalization > Colors): text readable everywhere, the sepia of
      "Them" included; nothing is system blue.
- [ ] Text scaling at 150 % (Settings > Accessibility > Text size): nothing clipped or overlapping.
