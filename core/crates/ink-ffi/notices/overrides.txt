# Licence texts for crates in the release whose published package carries no text of any licence
# it offers. ink-notices (core/crates/ink-ffi/src/bin/ink-notices) uses a line only for the crate
# version it names, and only while that package still lacks the text; a line no crate needs is an
# error, so a version bump means reading the new package again.
#
#   <crate> <version> <text file in texts/> <reason: shown in the app beside the text>
#

# - Apache-2.0.txt: the Apache License 2.0 as the Apache Software Foundation publishes it, byte for
#   byte (sha256 cfc7749b96f63bd31c3c42b5c471bf756814053e847c10f3eb003417bc523d30), from zeroize
#   1.9.0's LICENSE-APACHE. For crates that offer Apache-2.0 and name no author for MIT's notice.
# - MIT.txt: the MIT licence without a copyright line, byte for byte as serde, anyhow and the tract
#   crates ship it, from tract-core 0.23.8's LICENSE-MIT. ink-notices puts the crate's authors from
#   its manifest above it, marked as such, as for any MIT file that names no holder.
# - MIT-objc2.txt: MIT.txt under the author objc2, block2 and objc2-encode name in their manifests,
#   for objc2-foundation, from the same repository, whose manifest names none.
# - nom-8.0.0-LICENSE.txt: nom 8.0.0's LICENSE; nom-language lives in nom's repository.
#
